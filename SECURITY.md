# Security Policy

WardConnect stores personal information belonging to Chemoot Ward
residents. Security issues are treated seriously.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Report privately to: **security@wardconnect.local** (replace with a real
address before launch) with:

- A description of the issue
- Steps to reproduce
- The affected URL or file
- Any suggested fix (optional)

You will receive an acknowledgement within 72 hours.

## Scope

- Code in this repository
- Live deployments under the official WardConnect domain
- Database access rules (role scope helpers in `app/Middleware/`)

## Out of scope

- Denial-of-service from external network flooding
- Vulnerabilities in third-party dependencies already reported upstream
- Social engineering

## What we will never ask you for

- Your password
- Full copies of the production database
- Real resident records
